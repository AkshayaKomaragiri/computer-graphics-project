Data & analysis methods

Heightmaps and geographic bounds are supplied by this project and labeled NASA MOLA MEG128. Each 141 × 129 grayscale image is decoded using its per-region elevation range. Eight-bit encoding quantizes elevation into 256 levels; subtle features and fine slopes cannot be resolved.

Slope is the angle of the elevation gradient using latitude-adjusted spacing on a spherical Mars (radius 3,389.5 km). Roughness is the RMS elevation residual from a fitted plane in a 3 × 3 neighborhood, in meters. Area fractions use latitude and edge weighting. Profiles use bilinear sampling along a straight line in map coordinates, with geographic segment distances.

The 3D mesh uses bilinear interpolation. Contours and surface colors are visualization aids. The slope layer is scaled to 15° and roughness to each region's 95th percentile; values beyond those limits use the highest color. Vertical exaggeration changes geometry only. Gentle ground is an exploratory ranking, not a landing or rover safety assessment.
